🚀 Proyecto: Urban Grocers

Problema: Nuevas Actualizaciones.

Qué hice: En base a los nuevos requisitos de la actualización, organicé y creé casos de prueba para cada una de las endpoints solicitadas. Asegurándome que cada una de ellas funcione de manera correcta, asegurándome que la API esté en correcto funcionamiento en todo momento. Reportando en JIRA cualquier bug o error de la API.

Ejecuté 30 casos de prueba asegurando estabilidad del sistema. Reporté errores críticos, optimizando la experiencia del usuario.

Resultado y Aprendizaje: En este proyecto, el resultado fue exitoso, ya que la nueva actualización no contó con muchos errores y todas las pruebas descartaron un mayor problema futuro. Asimismo, desarrollé un mejor uso de mis herramientas como JIRA y POSTMAN, utilizando de manera correcta el POST para cada una de las pruebas y creando un ambiente más sencillo de trabajar.

📋 Proyecto - API Testing (Urban Routes)

Problema: Diseños y Requisitos para compartir automóvil Validaciones.

Qué hice: Con base a los requisitos me aseguré que diferentes navegadores y sistemas puedan solicitar compartir un auto, en FIGMA verifiqué todo el flujo para compartir un automóvil creando casos prueba para cada botón y lista de comprobaciones utilizando JIRA para reportar errores y bugs.

Ver documentación en Google Drive

Resultado y Aprendizaje: El resultado fue que en otros sistemas no se podía generar la cancelación y reservar el automóvil utilizando la lista de comprobación. En los casos de prueba que publiqué en JIRA, todos los errores se deben priorizar, debido a que el cliente no podría reservar, lo que impacta a la empresa de manera negativa.
